# ✦ Minimalist Portfolio Website

> A high-performance, single-page application (SPA) portfolio designed to showcase professional skills, projects, work experience, certifications, and educational background.

---

## ✨ Features

- **Interactive Creative Gallery:** Responsive photo/art grid with a category filter, marquee preview, and a full-screen interactive lightbox viewer.
- **MDX Blog Engine:** Dynamic routing rendering articles parsed from local markdown/MDX files. Features syntax highlighting and rich markdown formatting.
- **Responsive Layout & Floating Dock:** Adaptive navigation bar designed as a floating, centered pill dock on mobile devices.

---

## 💻 Technology Stack

- **Framework:** Next.js 16 (React 18, App Router)
- **Language:** TypeScript 5.8+ (Strict Mode)
- **Styling:** Vanilla CSS
- **Animations:** Framer Motion
- **Markdown Processing:** MDX, Shiki, Rehype Pretty Code, Remark GFM, Gray Matter
- **Icons:** `@tabler/icons-react` & Lucide React

---

## 🚀 Getting Started

### Prerequisites

Ensure you have Node.js and npm (or Bun) installed on your machine.

### Installation & Setup

1. **Clone the repository:**

   ```bash
   git clone https://github.com/eatulrajput/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**

   ```bash
   npm install
   # or using Bun
   bun install
   ```

3. **Start the development server:**

   ```bash
   npm run dev
   # or using Bun
   bun dev
   ```

4. **Open the app:**
   Navigate to [http://localhost:3000](http://localhost:3000) in your browser to see the portfolio.
